About This Project

Problem

Many gym-goers, especially beginners, do not always know what exercises to do when certain equipment is unavailable.

Solution

This web app uses the wger API to show exercise data and lets users save favorite exercises using Supabase.

Technologies Used

HTML, CSS, JavaScript, Node.js, Express, Supabase, Chart.js, and Swiper.js.
